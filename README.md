# 乐趣答题 · 产品展示网页

答题产品的静态展示页，使用 HTML、CSS、JavaScript、Bootstrap、jQuery 及轮播/动画插件。页面包含冒险模式、挑战模式、个人主页等产品展示区与截图。

## 当前仓库范围

- `index.html`：页面内容与展示结构。
- `js/main.js`：导航、滚动、轮播与交互初始化。
- `js/contact-form.js`：联系表单脚本。
- `images/`、`css/`、`style.css`：截图、素材和样式。

图片中展示的登录、题目、排行榜等界面，不代表这些业务已由本仓库实现。当前文件树中未发现业务后端、数据库迁移或可独立运行的移动端工程。

## 本地预览

```sh
python -m http.server 8000 --bind 127.0.0.1
```

在仓库根目录执行后打开 http://127.0.0.1:8000/ 。

本地静态预览不提供联系表单邮件服务。联系表单脚本来自已有第三方模板，页面和素材的原创范围应以个人实际贡献为准。

适合作为产品说明、页面呈现或团队展示材料。若简历主张开发了完整答题平台，需要另提供实际应用代码、本人负责模块与验证结果。
